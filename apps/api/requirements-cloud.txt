# SyncForge AI - API dependencies for cloud/container deploys (Render, Fly, Railway, Docker).
#
# Lean subset of requirements.txt: everything the FastAPI app imports at runtime,
# minus the local-only heavyweights. Specifically excluded:
#   * faster-whisper / soundfile / numpy -> local STT; the cloud uses Groq Whisper
#     (STT_ENGINE=groq_whisper). stt.py imports faster_whisper lazily behind a
#     try/except, so the app runs fine without it.
#   * celery / redis / flower -> worker-only modules that the web service never
#     imports (see app/workers/), so no broker is required to serve the API.
#   * ollama / openai / instructor / tiktoken -> the LLM client talks to the
#     OpenAI-compatible HTTP endpoints directly via httpx.
#   * PyGithub -> the GitHub integration uses the REST API via httpx.
